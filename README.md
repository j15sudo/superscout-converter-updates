# Superscout Converter Updates

This public repository hosts signed releases and the Sparkle update feed for
Superscout Converter.

## Security

- Release applications are signed with Apple Developer ID and notarized by Apple.
- Update archives are signed with Sparkle EdDSA signatures.
- The update-signing private key and application source code are not stored here.

Users should install v2.20 manually once. Superscout Converter v2.20 and later
can check and install subsequent updates from within the app.
